# לוח המשימות של הבית

אפליקציית משימות משפחתית עם נקודות. כל בן משפחה מסמן "סיימתי" מהטלפון שלו ומקבל נקודות. רק הורה מחובר יכול להוסיף משימות, לשנות ניקוד ולתת או להוריד נקודות.

- **האתר עצמו**: GitHub Pages (חינם)
- **הנתונים**: Firebase (חינם בהיקף של משפחה)
- **ההתקנה**: "הוסף למסך הבית" בטלפון. נפתח כמו אפליקציה, עם אייקון ומסך מלא.

זמן הקמה משוער: 15 עד 20 דקות.

---

## שלב 1: Firebase (המקום שבו הנתונים נשמרים)

1. נכנסים ל-https://console.firebase.google.com עם חשבון הגוגל שלכם.
2. **Create a project** → נותנים שם, למשל `family-tasks` → את Google Analytics אפשר לכבות → Create.
3. בתפריט בצד: **Build → Firestore Database → Create database**
   - Location: בחרו מיקום באירופה, למשל `eur3`.
   - בחרו **Start in production mode** → Create.
4. בלשונית **Rules** של Firestore:
   - מוחקים את מה שיש שם ומדביקים את כל התוכן של הקובץ `firestore.rules`.
   - **חשוב:** מחליפים את `ADMIN_EMAIL` בכתובת ה-Gmail שלכם. אם יש הורה שני, מוסיפים גם את הכתובת שלו, לפי ההסבר בקובץ.
   - לוחצים **Publish**.
5. בתפריט בצד: **Build → Authentication → Get started → Sign-in method**
   - מפעילים את **Anonymous**. דרך זה הילדים נכנסים בלי סיסמה.
   - מפעילים את **Google**. דרך זה ההורה נכנס. בוחרים מייל תמיכה ושומרים.
6. רושמים את האפליקציה:
   - לוחצים על גלגל השיניים → **Project settings** → למטה **Your apps** → לוחצים על האייקון `</>` (Web).
   - נותנים שם → **Register app** (לא צריך לסמן Hosting).
   - מעתיקים את הבלוק `const firebaseConfig = { ... }`.

## שלב 2: GitHub (המקום שבו האפליקציה יושבת)

1. ב-github.com לוחצים **New repository**.
   - השם: `family-tasks`.
   - **Public**: בחשבון החינמי, GitHub Pages עובד רק עם ריפו ציבורי. הקוד יהיה גלוי, אבל הנתונים שלכם לא.
   - Create.
2. **Add file → Upload files** → גוררים את **כל הקבצים והתיקייה `icons`** מהתיקייה הזו → Commit.
3. פותחים בריפו את הקובץ `firebase-config.js` → לוחצים על העיפרון (Edit) → מחליפים את כל ה-`PASTE_HERE` בערכים שהעתקתם מ-Firebase → Commit.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, תיקייה `/ (root)` → Save.
5. אחרי דקה או שתיים הכתובת תופיע למעלה: `https://<שם-המשתמש>.github.io/family-tasks/`

## שלב 3: לחבר את שני הצדדים

ב-Firebase: **Authentication → Settings → Authorized domains → Add domain** → מוסיפים `<שם-המשתמש>.github.io`.

בלי הצעד הזה, כניסת ההורה עם גוגל לא תעבוד.

## שלב 4: להתחיל להשתמש

1. פותחים את הכתובת בדפדפן במחשב או בטלפון.
2. לוחצים **5 פעמים מהר על הכותרת** "לוח המשימות של הבית" ונכנסים עם הגוגל שלכם. מופיעה לשונית **ניהול**. אין בממשק שום כפתור או כיתוב שמסגיר שיש מנהל. יוצאים דרך הכפתור **יציאה** בתחתית לשונית הניהול.
3. בלשונית ניהול:
   - מוסיפים את בני המשפחה.
   - מוסיפים משימות: חוזרות בימים מסוימים, או חד-פעמיות.
4. התקנה על הטלפונים:
   - **אייפון**: פותחים את הכתובת ב-**Safari** → כפתור השיתוף → **הוסף למסך הבית**.
   - **אנדרואיד**: פותחים ב-**Chrome** → תפריט ⋮ → **התקן אפליקציה** (או "הוסף למסך הבית").
5. בכל טלפון בוחרים פעם אחת למעלה את השם של מי שמשתמש בו, וזה נשמר.

## דברים שכדאי לדעת

- **כניסה לניהול באייפון**: באפליקציה המותקנת, החלון של גוגל לפעמים לא נפתח כמו שצריך. אם זה קורה, נהלו מ-Safari הרגיל או מהמחשב. הילדים לא צריכים להתחבר בכלל, אז אצלם זה לא משנה.
- **מה הילדים יכולים לעשות**: רק לסמן משימה שקיימת כבוצעה, בניקוד שקבעתם. הם יכולים לבטל סימון עד 12 שעות אחרי. אי אפשר לזייף נקודות, גם לא דרך הקוד, כי חוקי האבטחה של Firebase חוסמים את זה.
- **שינוי ניקוד של משימה**: חל רק מעכשיו והלאה. נקודות שכבר ניתנו לא משתנות.
- **בלי אינטרנט**: האפליקציה נפתחת, וסימונים נשמרים כשהחיבור חוזר.
- **עדכון האפליקציה**: מעלים קבצים חדשים ל-GitHub, והטלפונים יקבלו אותם בפתיחה הבאה.

## הקבצים

| קובץ | מה הוא עושה |
|---|---|
| `index.html`, `style.css`, `app.js` | האפליקציה עצמה |
| `firebase-config.js` | ההגדרות מ-Firebase (הדביקו כאן) |
| `firestore.rules` | חוקי האבטחה (מדביקים ב-Firebase, לא חובה להעלות ל-GitHub) |
| `manifest.json`, `sw.js`, `icons/` | מה שהופך את האתר לאפליקציה שאפשר להתקין |
